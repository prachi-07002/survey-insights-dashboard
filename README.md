# survey-insights-dashboard

Analyze Likert-scale survey results plus open-ended responses for STEM
education interventions, with breakdowns by intervention group, means,
distributions, and a self-contained static HTML report.

Built for Prachi Payasi's Spring 2027 Honors College research project
**"Analyzing STEM Education Interventions via Qualitative Data Analysis"**
(Prof. Lisa B Bosman) — qualitative analysis of interventions including
GenAI in Project Management, Social Justice in Calculus, and the
Autoethnography with PMaster Game. The pipeline mirrors the project's
real workflow (survey data → descriptive stats by group → open-ended
keyword themes → shareable report for poster/manuscript dissemination),
using only fictional sample data.

## What it does

- Parses a survey CSV (stdlib `csv`) and validates every Likert response
  is an integer in the 1–5 range.
- Computes per-item mean, median, standard deviation, and 1–5 score
  distributions, overall and broken down by intervention group.
- Compares groups: highest/lowest group mean and the max–min gap per item.
- Summarizes open-ended responses with simple tokenization + word
  frequency (no NLP dependencies), overall and per group.
- Generates a self-contained `report.html` — tables plus CSS bar charts,
  no JavaScript, no external CDN.

## Stack

Python 3 standard library only (NumPy is allowed but not required — this
project uses only stdlib). No binary files; everything is plain text.

## How to run

```bash
# Demo: load the sample survey, print stats, generate report.html
python3 main.py

# With custom paths
python3 main.py --csv data/sample_survey.csv --out report.html

# Tests
python3 -m unittest discover -s tests -v
```

Open `report.html` in any browser after running the demo.

## Data

`data/sample_survey.csv` — 50 fictional respondents (no real personal data):

| Column | Description |
|---|---|
| `respondent_id` | Fictional ID, R001–R050 |
| `intervention_group` | GenAI in Project Management / Social Justice in Calculus / PMaster Game |
| `confidence`, `engagement`, `perceived_fairness`, `genai_usefulness` | Likert items, 1–5 |
| `open_ended` | One free-text response per respondent |

Sample sizes: GenAI in Project Management n=18, Social Justice in
Calculus n=16, PMaster Game n=16.

## Headline results (fictional sample, N=50)

Overall means (1–5 scale):

| Item | Mean | Median | Std dev |
|---|---|---|---|
| Confidence | 3.90 | 4.0 | 0.81 |
| Engagement | 3.86 | 4.0 | 0.86 |
| Perceived fairness | 3.92 | 4.0 | 0.78 |
| GenAI usefulness | 3.88 | 4.0 | 0.90 |

Group means:

| Item | GenAI in PM | Social Justice in Calc | PMaster Game |
|---|---|---|---|
| Confidence | 4.06 | 3.69 | 3.94 |
| Engagement | 3.56 | 3.44 | 4.62 |
| Perceived fairness | 3.72 | 4.31 | 3.75 |
| GenAI usefulness | 4.44 | 3.38 | 3.75 |

Largest group differences (max group mean − min group mean):

- **Engagement: gap 1.19** — PMaster Game (4.62) vs Social Justice in
  Calculus (3.44). The game format is the clear engagement winner.
- **GenAI usefulness: gap 1.07** — GenAI in Project Management (4.44) vs
  Social Justice in Calculus (3.38).
- **Perceived fairness: gap 0.59** — Social Justice in Calculus (4.31) vs
  GenAI in Project Management (3.72).
- **Confidence: gap 0.37** — GenAI in Project Management (4.06) vs Social
  Justice in Calculus (3.69). Smallest gap; confidence is similar across
  all three interventions.

Top open-ended keywords: project (19 mentions), feedback (11), helped
(11), game (10), ai (10), made (9), real (6), felt (6), simulation (5),
showed (5).

## Project structure

```
survey-insights-dashboard/
├── main.py                 # Demo entry point: load CSV -> stats -> report.html
├── csv_parser.py           # CSV loading + Likert 1-5 validation
├── stats.py                # Mean, median, std, distributions, group breakdowns
├── keywords.py             # Tokenization + word-frequency summary
├── report.py               # Self-contained static HTML report generator
├── data/
│   └── sample_survey.csv   # 50 fictional survey responses
├── tests/
│   ├── test_csv_parser.py  # Parsing, validation, sample-file load
│   ├── test_stats.py       # Mean/median/std/distribution + group logic
│   └── test_keywords.py    # Tokenization + frequency counting
└── report.html             # Generated by `python3 main.py`
```

## Tests

22 unit tests, all passing (`python3 -m unittest discover -s tests -v`),
covering CSV parsing (valid rows, out-of-range/non-integer/missing-column
rejection, real sample file), mean/median/std/distribution on known small
data, group breakdowns and comparisons, and keyword tokenization/counting.
